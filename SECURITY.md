# Security

Self Host Layer runs as root on people's servers, so security reports matter a lot.

**Please don't open a public issue for a security problem.** Email **hello@selfhostlayer.com** with:

- what you found and where (file, action or page),
- how to reproduce it,
- what an attacker could do with it.

You'll get a reply within a few days. Once it's fixed and released, you'll be credited in the release notes if you'd like.

How apps are kept apart, what the panel can and can't do, and the known limits are written down in [docs/security.md](docs/security.md).
